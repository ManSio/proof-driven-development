# Research first

## Order

1. **State the question and the answer criterion** — what counts as an answer,
   what is only an opinion.
2. **Sources by priority:**
   - official documentation, specification, law, vendor site;
   - the primary data source (file, API, report);
   - reviews and articles — **secondary**, mark them as such.
3. **Read it, don't recall it.** Quote the fragment + link + date.
4. **Cross-check 2 sources** (3 for anything important). A contradiction shows
   both sides; never pick silently.
5. **Pin version/date.** Docs change; law changes.
6. **Report:** conclusion → evidence (links) → what was not verified.

## Citation format

```
[source: <name>, <URL>, checked 2026-01-01]
```

## When "not found"

A valid result. Say it plainly:

```
Searched: official site X (docs section), query "…", repo Y.
Result: no such information / access closed / version unspecified.
Conclusion: without this, Z cannot be claimed.
```

## Source quality

- Official domain? Publication date? Version?
- Does it link to the primary source, or is it a retelling of a retelling?
- An ad? Outdated (compare the date with today)?

## Forbidden

- inventing URLs or quotes;
- passing a secondary source off as a standard;
- "the internet says" without a link;
- concluding from a single source on an important question.
